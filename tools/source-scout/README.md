# ابزار بررسی منبع‌ها (اجرا روی کامپیوتر خودتان)

این ابزار روی کامپیوتر شما (که در ایران است) یک مرورگر Edge یا Chrome باز می‌کند و آدرس‌های فایل `urls.txt` را یکی‌یکی و با مکث بررسی می‌کند. برای هر آدرس معلوم می‌کند:

- RSS است یا صفحه؛
- چند خبر دارد، دسته‌های RSS آن چیست و چند درصد خبرها کلمه کلیدی (مثلاً «مشهد») را دارند؛
- لینک‌های خبر در صفحه چه الگویی دارند؛
- در صفحه آرشیو چه فیلترهایی هست (مثل شماره سرویس‌های مهر)؛
- متن کامل خبر در کدام بخش صفحه است.

در پایان، دو فایل `report.json` و `report.txt` در همین پوشه ساخته می‌شود. **فایل `report.json` را برای پیکربندی بفرستید.**

ابزار فقط صفحه‌های عمومی را می‌خواند، چیزی روی هاست شما اجرا نمی‌کند و چیزی به جایی نمی‌فرستد.

## یک بار: نصب

1. **Node.js** را نصب کنید: از [nodejs.org](https://nodejs.org) نسخه **LTS** را دانلود و نصب کنید (Next، Next، Install).
2. این پوشه (`source-scout`) را روی کامپیوتر داشته باشید.
3. در **VS Code** از منوی File ← Open Folder همین پوشه را باز کنید.
4. از منوی Terminal ← New Terminal یک ترمینال باز کنید و این دستور را بزنید:

   ```
   npm install
   ```

   مرورگر جدا دانلود نمی‌شود؛ ابزار از Edge یا Chrome خود ویندوز استفاده می‌کند.

## هر بار: اجرا

در ترمینال VS Code:

```
node scout.mjs
```

۴ پنجره مرورگر همزمان باز می‌شوند و سایت‌ها را موازی بررسی می‌کنند (دو آدرس از یک سایت هیچ‌وقت همزمان باز نمی‌شوند تا آن سایت شما را مسدود نکند). عکس و ویدئو دانلود نمی‌شود تا اینترنت کم مصرف شود. به پنجره‌ها دست نزنید. اگر سایتی صفحه «در حال بررسی مرورگر» (آروان یا کلادفلر) نشان داد، ابزار چند ثانیه صبر می‌کند تا رد شود. کل کار برای ۲۵ آدرس معمولاً ۲ تا ۴ دقیقه طول می‌کشد. پیشرفت کار در ترمینال نوشته می‌شود.

وقتی پیام «تمام شد» را دیدید، فایل **`report.json`** را بفرستید.

## تعداد مرورگرهای همزمان

پیش‌فرض ۴ است. برای ۶ تا (اگر کامپیوتر و اینترنت قوی است):

```
$env:WORKERS="6"; node scout.mjs
```

اگر کامپیوتر کند شد، عدد کمتری بدهید (مثلاً `"2"`).

## تغییر آدرس‌ها یا کلمه کلیدی

- آدرس‌ها در فایل `urls.txt` هستند؛ هر خط یک آدرس. خطی که با `#` شروع شود نادیده گرفته می‌شود.
- برای کلمه دیگر (پیش‌فرض «مشهد») در ترمینال ویندوز (PowerShell):

  ```
  $env:KEYWORD="تهران"; node scout.mjs
  ```

## اگر مشکلی پیش آمد

| پیام | راه حل |
|---|---|
| `npm` یا `node` شناخته نشد | Node.js نصب نشده یا بعد از نصب، VS Code را دوباره باز نکرده‌اید. |
| مرورگر Edge یا Chrome پیدا نشد | Google Chrome را نصب کنید. |
| خطای `npm install` (اتصال) | اتصال اینترنت را بررسی کنید و دوباره امتحان کنید. |
| یک سایت خطا داد | اشکالی ندارد؛ بقیه بررسی می‌شوند و خطا در گزارش ثبت می‌شود. |
| پنجره مرورگر را اشتباهی بستید | ابزار خودش دوباره بازش می‌کند و ادامه می‌دهد. |
