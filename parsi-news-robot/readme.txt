دریافت خودکار خبر از RSS سایت‌های دیگر با متن کامل، تصویر و ویدئو؛ پنهان از گوگل؛ دسته‌بندی بر اساس نقش دسته‌های سایت شما.

== Description ==

* دریافت متن کامل خبر: از خود RSS یا با باز کردن صفحه خبر (تشخیص خودکار + انتخابگر دلخواه برای هر منبع).
* تصویر شاخص و تصاویر متن در سه حالت: روی هاست شما، از هاست منبع، یا ترکیبی.
* ویدئوهای امبدشده (آپارات، یوتیوب، تلوبیون، نماشا و…) حفظ می‌شوند.
* نقش دسته‌ها از خود سایت خوانده می‌شود: موضوعی، بخش صفحه اصلی، ویدئو، عکس.
* بخش‌های صفحه اصلی با سه حالت تصادفی (دقیقاً یکی / شانس مستقل / بدون بخش) و سهمیه برای هر بخش.
* noindex، حذف از سایت‌مپ (رنک مث، Yoast، وردپرس)، جلوگیری از IndexNow و حذف از فید سایت.
* لینک‌هایی که ربات ساخته nofollow می‌شوند (قابل تغییر)؛ لینک‌های شما دست نمی‌خورند.
* «به نقل از» با متن، جا و مقصد لینک قابل تنظیم.
* حذف خودکار خبرها بعد از N روز با ریدایرکت ۳۰۱ به دسته اصلی.
* جلوگیری از خبر تکراری (حتی از منابع مختلف)، به‌روزرسانی خبرهایی که منبع تغییر داده، قوانین کلمه کلیدی، انتشار تدریجی و ساعت کاری.
* صف پس‌زمینه با Action Scheduler، درخواست شرطی (ETag)، فاصله هوشمند و جدول‌های اختصاصی دیتابیس.
* دستورات WP-CLI: `wp pnr run`، `wp pnr test <url>`، `wp pnr list`، `wp pnr cleanup`، `wp pnr log`.

== Installation ==

1. فایل zip افزونه را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. «ربات خبر ← دسته‌ها و بخش‌ها»: به دسته‌های سایت نقش بدهید.
3. «ربات خبر ← افزودن منبع»: آدرس RSS، دسته اصلی و بقیه تنظیمات را وارد کنید و «تست منبع» را بزنید.
4. «ربات خبر ← تنظیمات»: ایندکس، «به نقل از»، تصاویر و حذف خودکار را مرور کنید.
5. توصیه‌شده: دستور کران نمایش‌داده‌شده در «تنظیمات ← پیشرفته» را در کران‌جاب هاست بگذارید.
