# ربات خبر پارسی (افزونه وردپرس)

دریافت خودکار خبر از RSS سایت‌های دیگر با متن کامل، تصویر و ویدئو. خبرها از دید گوگل پنهان می‌مانند و فقط کاربر آن‌ها را می‌بیند. دسته‌بندی بر اساس نقشی است که شما به دسته‌های سایت می‌دهید.

- کد افزونه: [`parsi-news-robot/`](parsi-news-robot)
- فایل نصبی: [`dist/parsi-news-robot.zip`](dist/parsi-news-robot.zip)
- معماری و تصمیم‌ها: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## نصب

1. فایل `dist/parsi-news-robot.zip` را دانلود کنید.
2. در وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید، فایل را انتخاب کنید و افزونه را فعال کنید.
3. منوی «ربات خبر» در پیشخوان اضافه می‌شود. صفحه «پیشخوان» آن، مراحل راه‌اندازی و بررسی سلامت را نشان می‌دهد.

نیازمندی‌ها: وردپرس ۶.۵ به بالا، PHP ۷.۴ به بالا، و افزونه‌های PHP به نام DOM و mbstring (روی تقریباً همه هاست‌ها نصب هستند).

## راه‌اندازی در ۵ قدم

1. **دسته‌ها و بخش‌ها**: همه دسته‌های سایت شما آنجا نمایش داده می‌شوند. به هر دسته یک نقش بدهید:
   - **موضوعی**: مثل سیاسی و ورزشی. این دسته‌ها «دسته اصلی» منبع‌ها می‌شوند.
   - **بخش صفحه اصلی**: مثل تیتر یک، تیتر دوم و نوار کناری. برای هر کدام «شانس» و «سهمیه» تعیین کنید؛ سهمیه می‌تواند نامحدود، محدود (N خبر در X ساعت) یا صفر باشد.
   - **ویدئو** و **عکس**.
2. **افزودن منبع**: آدرس RSS را وارد کنید. اگر آن را نمی‌دانید، آدرس سایت را بزنید و «پیدا کردن خودکار» را امتحان کنید. بعد دسته اصلی را انتخاب کنید.
3. در همان صفحه، تب **تست منبع** را باز کنید تا ببینید خبرها چطور دریافت می‌شوند؛ هیچ خبری منتشر نمی‌شود. اگر متن کامل نبود، در تب «محتوا» انتخابگر CSS متن را وارد کنید.
4. **تنظیمات** را مرور کنید: ایندکس نشدن (پیش‌فرض روشن)، نوع لینک‌ها، «به نقل از»، محل تصاویر و حذف خودکار.
5. **توصیه‌شده**: دستور کرانی که در «تنظیمات ← پیشرفته» نمایش داده می‌شود را در کران‌جاب هاست بگذارید. در سایت‌های کم‌بازدید، زمان‌بند وردپرس فقط با بازدید اجرا می‌شود.

> **نکته مهم برای سایت‌های ایرانی:** بیشتر سایت‌های خبری ایران به سرورهای خارج از ایران جواب نمی‌دهند. اگر هاست شما خارج از ایران است، منابع ایرانی ممکن است کار نکنند. دکمه «تست منبع» این را همان اول نشان می‌دهد.

## قابلیت‌ها

| بخش | قابلیت |
|---|---|
| دریافت | RSS 2.0، Atom و RDF؛ درخواست شرطی (ETag) تا فید تغییرنکرده دوباره دانلود نشود؛ فاصله هوشمند؛ عقب‌نشینی خودکار برای منبعی که خطا می‌دهد؛ ساعت کاری؛ انتشار تدریجی |
| متن کامل | اول از خود RSS، بعد انتخابگر دلخواه، بعد الگوهای رایج سیستم‌های خبری ایرانی (`.item-text`، `.body`، `#echo_detail` و…) و در نهایت الگوریتم تشخیص خودکار؛ لید خبر؛ حذف «انتهای پیام»، «کد خبر»، لینک کوتاه، «پربیننده‌ترین‌ها» و بخش‌های مشابه |
| تصاویر | سه حالت: روی هاست شما، از هاست منبع، یا ترکیبی (پیش‌فرض)؛ پشتیبانی از تصاویر lazy-load؛ حذف عکس تکراری تصویر شاخص از متن؛ بررسی واقعی نوع فایل؛ SVG هرگز دانلود نمی‌شود |
| ویدئو | آپارات (حتی کد امبد اسکریپتی)، یوتیوب، تلوبیون، نماشا، ویمئو و ویدئوی خود منبع؛ فایل ویدئوی داخل RSS؛ `og:video` صفحه |
| دسته‌بندی | دسته اصلی (به‌عنوان دسته اصلی رنک مث هم ثبت می‌شود)، دسته‌های ثابت اضافه، بخش‌های صفحه اصلی در سه حالت تصادفی با سهمیه، دسته ویدئو، دسته عکس، و قوانین کلمه کلیدی |
| سئو | `noindex, follow` در رنک مث، Yoast و خود وردپرس، به‌همراه هدر `X-Robots-Tag`؛ حذف از هر سه سایت‌مپ؛ جلوگیری از ارسال به IndexNow رنک مث؛ حذف از فید سایت؛ امکان noindex برای صفحه دسته‌ها؛ استثنا برای هر منبع یا هر خبر |
| لینک‌ها | فقط لینک‌هایی که ربات ساخته `nofollow` می‌شوند (قابل تغییر به `follow` یا حذف لینک)؛ لینک‌های شما دستکاری نمی‌شوند |
| تکراری | خبری که یک بار دیده شده دیگر وارد نمی‌شود، حتی بعد از حذفش؛ عنوان‌های مشابه از منابع مختلف هم تشخیص داده می‌شوند |
| به‌روزرسانی | اگر منبع خبر را تغییر دهد (مثلاً نتیجه زنده بازی)، خبر سایت شما هم به‌روز می‌شود، به‌جز خبرهایی که دستی ویرایش کرده‌اید |
| حذف خودکار | بعد از N روز (برای هر منبع جداگانه)، با ریدایرکت ۳۰۱ به دسته اصلی، ریدایرکت به صفحه اصلی، یا کد ۴۱۰؛ تصاویر هم حذف می‌شوند؛ «نگه‌دار» برای هر خبر؛ دکمه «حذف همه خبرهای یک منبع» |
| دیتابیس | جدول‌های اختصاصی به جای ده‌ها ردیف متا؛ بدون revision و پینگ‌بک برای خبرهای ربات؛ پاک‌سازی دوره‌ای گزارش‌ها |
| مدیریت | پیشخوان با بررسی سلامت، گزارش‌ها، سطح دسترسی قابل واگذاری به نقش‌های دیگر، و دستورات WP-CLI |

## دستورات WP-CLI

```bash
wp pnr run --all                 # بررسی همه منابع و انتشار خبرهای در صف
wp pnr run --source=12           # فقط یک منبع
wp pnr test https://example.com/rss --items=2   # پیش‌نمایش بدون انتشار
wp pnr list                      # وضعیت منابع
wp pnr log --limit=30            # آخرین گزارش‌ها
wp pnr cleanup                   # اجرای حذف خودکار
wp pnr sync                      # همگام‌سازی دوباره وضعیت ایندکس
```

## ساخت فایل نصبی

```bash
./build.sh   # خروجی: dist/parsi-news-robot.zip
```
